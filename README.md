# AIニケフェス

AIニケフェスの年別特設サイトを管理するリポジトリです。

各年のサイトは、それぞれのフォルダ内で完結する独立したアプリケーションとして管理します。コンポーネント、モジュール、依存パッケージ、ビルド設定、デプロイ設定は年をまたいで共有しません。

## 年度別サイト

| 年度 | 特設サイト | ソースコード |
| --- | --- | --- |
| 2026 | [AIニケフェス2026](https://fes2026.nikechan.com/) | [`2026/`](./2026/) |

## 新しい年を追加するとき

新しい年のフォルダを作り、その年の企画と技術選定に合わせてゼロから構成します。過去年度のコードを共通モジュール化せず、必要な内容だけを参考にします。
